# Security Policy

## Supported Versions

Only the latest version of the Awesome list is supported with security updates.

## Reporting a Vulnerability

We take security seriously. If you find a security vulnerability (such as a link pointing to a malicious site or compromised packages), please do not disclose it publicly. Instead, report it privately using GitHub's private vulnerability reporting feature under the **Security** tab of this repository.

Please provide a clear description of the issue and potential impact. We will coordinate a resolution promptly.
